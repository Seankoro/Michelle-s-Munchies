## Verified by hand and fixed

### fetchRefundedCents answered zero when its read failed

In `src/lib/admin-db.ts`. The double refund guard read a failed query as nothing has gone back, so a cancel would send the whole total on top of money already returned. It now refuses and the cancel stops.

### A refund that left Stripe was recorded after the order update

In `src/lib/admin-db.ts`. A failed order update returned early and the order_refunds row was never written, so the money was gone with nothing showing it and the retry sent it again. The row is written first now, and a failure to write it stops the cancel and says so.

### A failed admin load was marked as loaded

In `src/components/admin/AdminStore.tsx`. Every admin page reads hydrated as the real data is here. Set after a failure it handed them empty arrays and default settings to present as fact, and the settings form offered to save default delivery zones over her own. Only a load that returned counts now, and the error banner carries a Try again.

### Modal scroll lock did nothing

In `src/lib/useDialog.ts`. globals.css sets overflow-x: clip on html, which stops body overflow reaching the viewport, so hiding body did nothing and the page scrolled behind every sheet and drawer. The html element is locked too.
